# COLT testimonials folder

Drop testimonial media here. Mix of videos + images is fine.

**Naming convention:**
- `creator-name-usd.mp4` or `.jpg` or `.png`
- Example: `jess-usa-2847.mp4`, `tom-uk-1932.jpg`
- Keep lowercase, dash-separated, no spaces or special characters

**After dropping files:**
Tell Claude the filenames + caption text and the lander will wire
them into the Testimonials section of /colt.

Video testimonials auto-play muted with a controls bar.
Image testimonials render as photo cards with the creator's name
and country below.
